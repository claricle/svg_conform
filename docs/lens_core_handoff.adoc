== Adopting

Pin the exact commit, never a branch:

[source,ruby]
----
gem "lens_core", git: "https://github.com/claricle/lens_core.git",
                 ref: "d8903de61dec5b600853e1d605a712cc83f99c41"
----

Canonical calls:

[source,ruby]
----
report = LensCore::Parsers::Json.parse(File.binread("report.json"))  # or Parsers::Yaml
LensCore::Renderers::Json.render(report)   # canonical bytes
LensCore::Renderers::Yaml.render(report)
LensCore::Renderers::Human.render(report)
----

Rendering a parsed canonical golden returns the input bytes exactly. Timestamps
are omitted unless the producer passes one.

== Compatibility and errors

* A `schema_version` other than `1` raises `LensCore::UnsupportedVersionError`;
  a non-integer one raises `LensCore::SchemaError`.
* Within version 1 consumers accept new `kind` values and unknown members.
  Removing a member, changing its meaning, or adding a `severity` or location
  `type` is a new schema version.
* Other failures are `LensCore::ParseError`, `UnsafeYamlError`,
  `InvalidEncodingError` and `SchemaError` (with the failing path).
* `summary` is derived and checked on parse; `valid: true` with an error is
  rejected. The full rules are in LensCore `docs/diagnostics-v1.adoc`.

== Evidence completed

* Three real svg_conform exports in `spec/fixtures/v1/golden/svg_conform/`:
  SVG 1.1 invalid CSS grammar, SVG 2 external reference, and a four-channel
  report (error, validity error, warning, info) built through the public
  `SvgConform::Diagnostics::LensCoreAdapter`.
* Each golden validates against the schema, parses, and renders byte for byte;
  summary counts equal the diagnostics.
* `spec/fixtures/host_app/` reads the whole golden directory using LensCore
  alone (no svg_conform, no other lens).
* `script/refresh_svg_goldens PATH_TO_SVG_CONFORM` regenerates the three SVG
  goldens from a checkout at the manifest's producer commit.

== Not evidence

`spec/fixtures/v1/golden/examples/binary-location.json` is a format-neutral
contract example of the binary location form. It is not PNG, EMF or PostScript
implementation evidence; no lens other than svg_conform has adopted LensCore.
